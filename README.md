# 🏰 Vương Quốc Tri Thức - Game Học Tập Tiểu Học (GDPT 2018)

> Nền tảng game web học tập tương tác bám sát chuẩn chương trình Giáo dục Phổ thông 2018 dành cho học sinh tiểu học (Toán, Tiếng Việt, Tiếng Anh, Khoa Học).

🌐 **Chơi Trực Tuyến:** [https://mrlute88.github.io/gametieuhoc/](https://mrlute88.github.io/gametieuhoc/)

---

## 🌟 Điểm Nổi Bật

* **122 Ải Thử Thách Phong Phú:**
  * 🔢 **Đảo Toán Học (32 Ải):** Đếm số, cộng trừ phạm vi 10 và 20, hình khối, xem giờ, số tròn chục, bảng nhân chia 2 & 5.
  * 📖 **Rừng Tiếng Việt (30 Ải):** 5 dấu thanh điệu, ghép vần, chính tả C/K, G/GH, NG/NGH, mẫu câu, đọc hiểu thơ và ca dao.
  * 🌍 **Thung Lũng Tiếng Anh (30 Ải):** Phonics, màu sắc, động vật, số đếm, gia đình, giới từ on/under, hội thoại giao tiếp.
  * 🌱 **Xứ Sở Khoa Học (30 Ải):** Giác quan, cây xanh, an toàn giao thông, 4 mùa, nam châm, chuỗi thức ăn và bảo vệ môi trường.
* **Đấu Trí RPG Phi Bạo Lực:** Sử dụng engine **Phaser.js 3** mô phỏng trận đấu giải đố trí tuệ với các đối thủ thần tiên thân thiện.
* **Cơ Chế Giáo Dục Không Trừng Phạt (Scaffold System):** Khi sai không trừ máu; tự động bung gợi ý trực quan từng bước giúp bé tự khám phá đáp án.
* **Mini-Game "🏎️ Đua Xe Tính Nhẩm 60s":** Rèn luyện phản xạ tính nhẩm tốc độ, xả stress sau các bài học sâu.
* **Vườn Linh Thú & Tiệm Trang Phục:** Nuôi dưỡng và tùy biến Pet (Rồng con, Cú thông thái, Cáo vàng, Kỳ lân).
* **An Toàn Trẻ Em & Cổng Phụ Huynh:** Xác thực Parental Gate bằng toán học; tự động nhắc nhở nghỉ ngơi sau 30 phút; tuân thủ COPPA & Nghị định 13 (Zero PII).

---

## 🛠️ Công Nghệ Sử Dụng

* **Frontend:** React 19 + Vite
* **Game Engine:** Phaser.js 3 / Canvas 2D
* **Hiệu ứng:** Canvas Confetti + Web Audio API (âm thanh thời gian thực) + Web Speech Synthesis (đọc câu hỏi tiếng Việt & tiếng Anh)
* **Triển khai:** GitHub Pages & GitHub Actions CI/CD

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

```bash
# 1. Clone repository
git clone https://github.com/mrlute88/gametieuhoc.git
cd gametieuhoc

# 2. Cài đặt thư viện
npm install

# 3. Chạy môi trường phát triển
npm run dev

# 4. Build bản chạy thử
npm run build
```
